# 0.2.13 低持跑步与动态衔接修正候选

安装包SHA256：`d2df975a8eeda6547eac7e0cef529cc3519a4c73dec55fa8159c5673686a720a`。最终测试前逐一核对安装目录全部40个文件与ZIP相同；实机范围以runtime-verification.json为准。

0.2.12复核发现衔接端点混合误改根/镜头轨迹，已撤回为草稿。本版将影响范围限制为手臂和武器分支，新增逐帧原生根/镜头轨迹检查。

本版按用户确认将普通跑步改为右侧低持摆动。采用原生sprint_0的步伐时间和方向变化，将位移摆幅保留20%、旋转摆幅保留25%，整体前移6单位以适配TF2固定镜头。双手随低持握点运动；进入/退出跑步匹配枪和双手端点，保留隐藏收放端及举枪完成端。特殊单手动作仍用单手循环。本版继续保留0.2.11针对枪声小、换弹缺少反馈、空中斜持不触发、开火左倾、握持松散及外接击杀屏位置调整：

- 首发样本峰值由0.20提高到0.65，连射由0.20提高到0.55，分别约+10.24/+8.79dB。保留停火尾音和原生低弹警告，没有恢复停火播放完整连射的旧错误。实际输出录音另记，不能把样本增益当作用户耳边声压。
- 原生Apex拔弹匣、插入、拉栓和手部归位声音映射到10个现有CAR换弹事件。使用原动画事件时序，保留中断/恢复行为；没有脚本重复播放整段换弹声。
- 蹲姿由实际蹲姿或IN_DUCK输入驱动，取消三维总速度限制，因此跳跃垂直速度不会取消斜持。斜持改为25度绕视线旋转并保持前后深度，避免枪尾圆筒扫入镜头。ADS保持瞄准姿势，换弹期间由原生换弹动作接管。
- 原CAR移动、跳起/落地和regrip层会把手独立拉离猎兽。15个相关增量条目改为现有spineC公共分支的整体运动，保留原根骨/镜头轨迹。开火也通过公共分支反馈，保留35%位移/俯仰与15%偏航，去掉沿视线的左滚。CAR弹道后坐力和武器数值未改。
- 外接击杀屏从原生绑定坐标(1.047551,47,11)改到(0.65,48.5,14)：上移1.5、前移3并收近侧面。两处短支架连接实际静态枪身表面；外壳和RUI使用相同安装骨骼与尺度。原生中央弹药屏保留。

69项单元检查和原动画表/事件核对通过。编译后另解码362帧移动/跳落/regrip与164帧攻击，以站立/ADS、多档叠加权重核对16,832个手指/手腕接触；另保留蹲姿混合检查。2476帧绝对动作和968帧换弹恢复继续核对。原124动画、97序列前缀及255条事件保持，合计133动画/98序列。没有新增骨骼，额外机制骨骼仍有实际网格用途。

实机结论：按用户确认改成右侧低持并随步伐摆动。冷启窗口私人比赛采集连续跑步、两次起停、跑步后开火换弹、站立与蹲姿/ADS开火、空中按蹲及停止恢复。编译后完整21帧低持循环检查通过；枪与双手过渡端点及循环接缝检查通过。保留原生根/镜头轨迹，编译后198个采样通过。只改变第一人称模型与版本号，0.2.11的声音、斜持及计数器安装完整保留。游戏正常退出；具体观感以最终录像为准。
