# Prowler.CAR.Scavenger 0.1.18

2026-10-27。**已完成构建、数据核对和 Blender 模拟（用游戏的真实飞行员手臂、110° 视野）；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原版动作，开枪时线圈转鼓每发转一格，线圈发光，枪声换成全自动猎兽。

## 本版修复（针对 0.1.17 实测：换弹时多出来的手、乱飞的弹匣）

- **原因：**
  - Apex 武器画面的视野是 70°，水平半角约 43°、垂直约 28°。猎兽换弹时，把旧弹匣甩出画面、再从画面下方拿新弹匣，这两步都恰好放在这个视野外（弹匣在水平 44°，随后瞬移到下方 47°；左手在水平 45°）。
  - 泰坦陨落2 的武器画面视野随玩家视野设置变化，最大到 110°（水平半角约 62°、垂直约 47°）。所以 Apex 藏在画面外的这些动作会出现在画面边缘：弹匣悬在半空、手从边缘伸出来。
- **修复：** 保留 Apex 原版动作。手或弹匣离开枪身、且 Apex 本来就把它放在画面外时，沿原方向继续往外推，直到也超出泰坦陨落2 最大视野，并平滑过渡。Apex 画面里看得到的部分完全不变。
- **另外说明：** 高速移动（如下落、长时间滞空）时左手离开枪、举到左上方，是泰坦陨落2 原版 CAR 也有的"挡风"动作（`wind_loop_layer`），本版保留。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 重点测换弹（空仓和非空仓都测）：弹匣是否还会在画面里悬空，手是否还会从画面边缘伸出来。
4. 连发：转鼓是否每发转一格，停火时是否停正。
5. 控制台：`prowler_car_spin 0` 关闭转鼓转动，`prowler_car_fx 0` 关闭线圈电弧特效。

禁用此模组即可恢复原版资源。
