# Prowler.CAR.Scavenger 0.1.19

2026-10-27。**已完成构建、数据核对和 Blender 模拟；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原版动作，开枪时线圈转鼓每发转一格，枪声换成全自动猎兽。本版没有任何光效。

## 本版修改（针对 0.1.18 实测：手错位、转鼓会飞；并按要求去掉光效）

- **参考成功案例：** 对比了两个能正常使用的 Apex→泰坦陨落2 第一人称移植模组（Nachos 的 Apex CAR、Echo 的进化 R99），两者都：
  - 骨骼和原版完全一样（CAR 85 根 / R97 88 根），一根都没加；
  - Apex 零件全部刚性绑在原版骨骼上，进化皮的可动零件也不例外。
- **0.1.11–0.1.18 的问题：** 我们额外加了 34 根骨骼，转鼓和下面的环都绑在这些新骨骼上。不管用哪种方式转，游戏里这部分始终会飞。
- **本版改法：**
  - 骨骼恢复为原版 85 根，顺序和原版一致（已加测试固定下来）；
  - 线圈转鼓绑到原版的枪栓骨骼 `def_c_bolt`，骨骼放在转鼓轴心，所有动作里都固定在枪上；开火时原版的枪栓后坐去掉，转鼓只转不动；
  - 下面的环、弹簧、管子、螺母等猎兽零件全部固定在枪身 `def_c_base` 上，不再单独运动；
  - 转鼓每发转一格（1/3 圈），由脚本控制，转的是原版骨骼；
  - 手臂处理保留上一版：肘部只弯不拧，Apex 藏在画面外的换弹动作推到泰坦陨落2 画面外。
- **去掉光效：** 线圈自发光（材质 selfillumtint）设为 0，开火电弧特效和 `prowler_car_fx` 开关已删除。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 第一人称：待机、开火、换弹、冲刺、开镜时，转鼓和枪身零件是否都在原位，手是否握在枪上。
4. 连发时转鼓是否每发转一格；如果仍然异常，可以在控制台输入 `prowler_car_spin 0` 关闭转动，转鼓就固定不动。

禁用此模组即可恢复原版资源。
