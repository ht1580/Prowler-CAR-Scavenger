# Prowler.CAR.Scavenger 0.1.20

2026-10-27。**已完成构建、数据核对和 Blender 骨骼可视化检查；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原版动作，开火时线圈转鼓旋转，枪声换成全自动猎兽。没有任何光效。

## 本版修改（针对 0.1.19 实测：转鼓一转就飞）

- **骨骼检查（可视化 + 数据，与原版 CAR、L-STAR 对比）：**
  - 只有左右两条手臂，都正确接在肩上并握在枪上；
  - 没有多余的手臂骨骼，也没有挂错父级的骨骼；
  - 肘部是纯铰链，手腕扭转在原版范围内；
  - 上臂辅助骨 15.9% 的长度差，原版 CAR 和 L-STAR 完全相同，属于原版设计。
- **原因：** 骨骼没有问题，问题出在转动方式。0.1.17–0.1.19 用的"脚本 + 姿态参数 + 常驻动画层"是我们自己设计的做法，原版武器没有这样用的。
- **改用原版做法：** 参照原版全自动武器 L-STAR 的转动部件，加一个名为 `fire_layer` 的循环增量动画层（无 activity，每圈 8 步、每步 45°，每秒 2 圈）。这个层由引擎在开火时按名字自动播放，只转转鼓骨骼（原版枪栓骨骼 `def_c_bolt`）。
- **删除：** 客户端脚本、姿态参数、额外附加点、`prowler_car_spin` 开关。现在动作序列、姿态参数、附加点、骨骼都与原版一致，只在最后多了一个 `fire_layer`。
- 如果引擎没有为 CAR 播放这个层，转鼓只是不转，不会飞。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 连发时转鼓是否转动、是否在原位；停火后是否回到静止。
4. 待机、换弹、开镜、冲刺时，手和枪身零件是否都在原位。

禁用此模组即可恢复原版资源。
