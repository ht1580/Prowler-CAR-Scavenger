# Prowler.CAR.Scavenger 0.1.16

2026-10-27。**已完成构建、数据核对和 Blender 第一人称模拟（使用游戏的真实飞行员手臂模型）；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原生动画，开枪时线圈转鼓随每发转动，线圈发光，枪声换成全自动猎兽。

## 本版修复（针对 0.1.15 实测）

- **第一人称手臂挡在镜头前 / "手飘在空中"：**
  - 原因：游戏按骨骼名把泰坦陨落2的飞行员手臂模型合并到武器模型上。猎兽的 Apex 骨架身体高约 2 个单位、肩膀前倾，所以肩膀和上臂跑到镜头前面；Apex 的手臂模型没有肩膀和袖子，泰坦陨落2 的有。
  - 修复：身体和肩膀换回原版 CAR 的姿态，肘部用 IK 重新计算。枪和双手的位置与猎兽动画完全一致。
- **声音容易炸：**
  - 原因：开火瞬间首发音效和循环音效同时播放，两者的峰值都在 −0.2 dBFS，叠加后在游戏混音里削波失真。
  - 修复：所有音效峰值降到 −6 dBFS，循环音效加软限幅。
- 第三人称大厅选枪界面里一只手张开展示，这应是选枪界面的展示姿势；请和原版 CAR 在同一界面对比确认。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 第一人称：待机、开火、换弹、冲刺、开镜时，镜头前是否还有手臂或"浮空的手"。
4. 连发时声音是否还会炸。
5. 控制台输入 `ns_print_played_sounds 1` 后开枪，确认播放的是小写事件名。

可用 `prowler_car_fx 0` 关闭线圈电弧特效。禁用此模组即可恢复原版资源。
