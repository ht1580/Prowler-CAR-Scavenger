# Prowler.CAR.Scavenger 0.1.15

2026-10-27。**已完成构建和数据核对；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原生动画，开枪时线圈转鼓随每发转动，线圈发光，枪声换成全自动猎兽。

## 本版内容

- **转鼓：** 旋转写在射击动画里，和枪栓后坐一起播放。每发线圈转鼓转 1 整圈，两个内环反向转 2 圈。全部 124 个动画解码检查，转鼓零件只绕自身轴转动，没有偏移或倾斜。
- **骨骼与绑定：** 按 HK560 教程合并骨架，猎兽骨骼挂在 `weapon_bone` 下；每个零件绑在自己的骨骼上；增量动画补齐新骨骼；`$bonemerge` 共 107 条；序列表与原版一致。
- **握持：** 右手握斜管握把，食指在第二个大环内扣扳机；左手握蓝色胶带前握把。第三人称为刚性放置，前手 IK 在胶带前握把上。
- **声音：** 事件名改为音频库中的小写名称并列出全部变体（11 个定义、62 个 EventId）；首发、循环、尾音为全自动猎兽声，SecondShot 静音。消音器事件仍为原版。
- **开枪模型飞起来：** 已修复（Crowbar 根骨 −90° 坐标修正按数据撤销）。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 控制台输入 `ns_print_played_sounds 1` 后开枪，确认播放的是小写事件名、听到的是全自动猎兽声。
4. 第一人称连发：转鼓是否连续转动、有没有错位，模型是否保持不动。
5. 第一和第三人称：手是否握在斜管握把和胶带前握把上。

可用 `prowler_car_fx 0` 关闭线圈电弧特效。禁用此模组即可恢复原版资源。
