# Prowler.CAR.Scavenger 0.1.17

2026-10-27。**已完成构建、数据核对和 Blender 模拟；尚未游戏内实测。**

把 Apex 猎兽（Prowler）进化皮「Scavenger」套到 CAR 上：第一人称用猎兽原生动画，开枪时线圈转鼓每发转一格，线圈发光，枪声换成全自动猎兽。

## 本版修复（针对 0.1.16 实测）

- **手臂拉伸、手形奇怪：**
  - 原因：泰坦陨落2 的手臂骨架中，肘部只能像铰链一样弯曲，不能绕上臂扭转。0.1.16 重定向手臂时没有遵守这一点，上臂最多扭了 88°，手腕最多扭了 169°，袖子和手套就被拧拉变形。
  - 修复：按原版 CAR 实测的骨架规则重建手臂：肘部只做铰链弯曲；肘部辅助骨按弯曲角度跟随（`0.5×弯曲角 + 20.5°`）；前臂扭转辅助骨承担手腕扭转的一半；肘部在允许范围内选择手腕扭转最小的位置。
  - 结果：所有动画的上臂扭转为 0，手腕扭转不超过 74°（原版 CAR 最多 88°）。
- **开枪时转鼓和下面的环乱转：**
  - 原因：0.1.14–0.1.16 把转鼓转动写在开火动画里。由于引擎每发都会重新叠加开火动画，只能每发转整圈，即转鼓每秒 14 圈、下面的环每秒 28 圈，看起来就是在乱闪乱飞。
  - 修复：改由客户端脚本控制模型姿态参数，每发转一个弹巢（1/3 圈），平滑跟随，停火时正好停在弹巢位置；下面的环跟着同速转动。开火动画只保留枪栓和弹簧后坐。

## 安装和测试

1. 关闭游戏，备份旧的 `Prowler.CAR.Scavenger` 模组目录。
2. 用 ZIP 中的完整同名目录替换旧版本，预期路径为 `Titanfall2\R2Vanilla\mods\Prowler.CAR.Scavenger\mod.json`。
3. 第一人称：待机、开火、换弹、冲刺、开镜时，手臂和手是否自然，有没有拉伸。
4. 连发：转鼓是否每发转一格、平稳，停火时是否停正。
5. 控制台：`prowler_car_spin 0` 关闭转鼓转动，`prowler_car_fx 0` 关闭线圈电弧特效。

禁用此模组即可恢复原版资源。
