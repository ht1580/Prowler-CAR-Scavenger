**已构建，骨骼经可视化与数据核对；尚未游戏内实测。**

针对 0.1.19 实测反馈（转鼓一转就飞）：

- **骨骼检查**（逐帧解码最终模型，对比原版 CAR 和 L-STAR）：只有左右两条手臂，接在正确位置，没有多余、错接或扭曲的骨骼；肘部是纯铰链，手腕扭转在原版范围内。
- **原因：** 骨骼没有问题，问题在转动方式。0.1.17–0.1.19 用的"脚本 + 姿态参数 + 常驻动画层"原版武器都不用，游戏里转鼓一转就飞。
- **改用原版做法：** 照抄原版全自动 L-STAR 的 `fire_layer`（循环增量动画层，无 activity，开火时由引擎按名字播放，序列标志 0x15 与 L-STAR 相同），只转转鼓骨骼 `def_c_bolt`，每圈 8 步、每步 45°，每秒 2 圈。
- **删除：** 客户端脚本、姿态参数、额外附加点、`prowler_car_spin` 开关。骨骼、姿态参数、附加点与原版一致，只多了一个 `fire_layer`。
- 如果引擎没有为 CAR 播放这个层，转鼓只会不转，不会飞。
- 没有任何光效。

安装：解压后把 `Prowler.CAR.Scavenger` 文件夹放进 profile 的 `mods` 目录（如 `R2Vanilla\mods`），替换旧版本。
