# Prowler.CAR.Scavenger 开发过程记录

本文按时间顺序整理整个任务：用户每轮的实测反馈、查到的原因、采取的修正、验证方法，以及仓库里各类日志和资料的位置。各版本的完整细节见 [版本说明.md](版本说明.md)（最新版本在最上面）。

> **状态说明：** 0.1.20 及之前的所有版本都**没有经过作者本机的游戏内实测**；游戏内结论全部来自用户或测试者的反馈。离线验证包括数据解码、编译结果检查和 Blender 模拟。

## 目标

把 Apex Legends 猎兽（Prowler）进化皮「Scavenger」移植到 Titanfall 2 的 CAR 冲锋枪上（Northstar 模组）。要求：

- 第一人称使用猎兽原版动作；
- 顶部线圈转鼓开火时转动；
- 换成全自动猎兽枪声；
- 准星、FOV、开镜、UI 保持原版可用。

## 主要排查方法

- **解码最终 MDL**：`decode_native_pose.ps1` 用 Crowbar 0.74 程序集，逐帧还原编译后的动画，确认游戏实际拿到的数据。
- **编译结果自洽性检查**：
  - `vtx_bones.py`：VTX 骨槽与 VVD 骨骼一致；
  - `check_pose_to_bone.py`：绑定矩阵正确；
  - `mdl_engine_dump.ps1`：v53 骨骼字段；
  - `anim_flags_compare.py`：动画与序列标志。
- **真实手臂模拟**：
  - `sim_fp_arms.py` 从 VPK 提取 TF2 飞行员第一人称手臂，按骨骼名合并后蒙皮并渲染；可用 `SIM_FOV=110` 模拟宽视野；
  - `arms_bone_report.py`、`arm_twist_report.py` 检查手臂骨骼位置和扭转。
- **骨骼核查（0.1.20）**：`skeleton_audit.py` 逐帧检查拓扑、左右手臂链数量、拉伸、肘部铰链、扭转，与原版 CAR、L-STAR 对比，并输出骨架线框图。
- **对照原版和成功案例**：`compare_ports.py`、`anim_desc_dump.py`、`compare_motion.py`、`spin_part_report.py`（原版 L-STAR / Softball / MGL 的转动部件）。
- **开火叠加模拟**：`sim_fire.py`（基础姿态 × 增量）、`sim_fire_blend.py`（14 发/秒下多层交叉淡入淡出）。
- **音频**：`audio_levels.py` 测峰值、RMS 和削波。
